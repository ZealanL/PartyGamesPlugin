# PartyGamesPlugin
Spigot 1.8.8 plugin to replicate 26 of Hypixel's arcade party games

### Games implemented:
- Animal Slaughter
- Anvil Spleef
- Avalanche
- Boat Race
- Bombardment
- Cannon Painting
- Chicken Rings
- Dive
- Fire Leapers *(but I made it way more fun)*
- Frozen Floor
- High Ground
- Hoe Hoe Hoe
- Jigsaw Rush
- Jungle Jump
- Lab Escape
- Lawn Moower
- Minecart Racing
- Pig Fishing
- Pig Jousting
- Punch The Bats
- Shooting Range
- Spider Maze
- Super Sheep
- The Floor Is Lava
- Trampolinio
- Volcano
- Workshop
